Objetivo da atividade

Criar a primeira versão do site pessoal usando somente HTML, sem CSS, frameworks CSS ou JavaScript. O foco é estruturar corretamente o documento e seu conteúdo, usando:

estrutura básica (<!DOCTYPE html>, <html>, <head> e <body>);
títulos, parágrafos, listas, hyperlinks e imagem;
navegação entre as seções da página;
formulário de contato com <form> (sem envio a servidor).
Como visualizar

Coloque index.html e foto.jpg na mesma pasta e abra o index.html no navegador.
